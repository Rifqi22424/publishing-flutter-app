# Kebijakan Privasi NusaJantung

Berlaku sejak 12 November 2026.

NusaJantung adalah aplikasi contoh mata kuliah Pemrograman Perangkat Mobile (IF31033), Universitas Nusa Putra.

## Data yang dicatat

Aplikasi menyimpan angka detak jantung, waktu pengukuran, dan catatan singkat yang Anda ketik sendiri.

## Tempat data disimpan

Semua data disimpan **hanya di HP Anda**. Aplikasi tidak memiliki izin internet, tidak mengirim data ke server mana pun, dan tidak membagikan data kepada pihak lain.

## Menghapus data

Geser catatan ke kiri untuk menghapusnya. Menghapus aplikasi akan menghapus semua catatan.

## Bukan alat medis

NusaJantung tidak mendiagnosis penyakit dan tidak menggantikan tenaga kesehatan. Dalam keadaan darurat, hubungi 119.

## Kontak

Pertanyaan tentang kebijakan ini dapat diajukan melalui halaman Issues di repository GitHub aplikasi ini.
